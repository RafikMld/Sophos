Sophos XGS 2300

Guide pratique : bloquer une adresse IP, configurer une règle Firewall et vérifier son fonctionnement.

Objectif : apprendre à créer un objet IP dans Sophos Firewall, ajouter une règle de blocage et contrôler les journaux. Les noms exacts des menus peuvent varier selon la version de SFOS.

Sommaire

  • 1. Identifier ce que tu veux bloquer
  • 2. Créer l'objet IP
  • 3. Créer la règle de blocage
  • 4. Vérifier que le blocage fonctionne
  • 5. Bloquer une IP interne
  • Documentation officielle

1. Identifier ce que tu veux bloquer

Il existe deux cas principaux :

Cas A — Bloquer une IP publique entrante

Une adresse IP publique provenant d'Internet tente d'accéder à ton réseau. Tu souhaites empêcher cette adresse d'atteindre les ressources internes.

Exemple : 203.0.113.50

Cas B — Bloquer une IP interne

Un poste de ton réseau local ne doit plus accéder à Internet ou communiquer avec certaines autres zones réseau.

Exemple : 192.168.1.50

Important : la configuration de la règle dépend du sens du trafic. Le blocage d'une IP publique entrante et celui d'un poste interne ne nécessitent pas les mêmes zones source et destination.

Les étapes 2 et 3 présentent d'abord la méthode pour bloquer une IP publique entrante depuis Internet vers le LAN.

2. Créer l'objet IP

Avant de créer la règle Firewall, ajoute l'adresse IP dans les objets réseau de Sophos. Cet objet pourra ensuite être sélectionné dans la règle.

Étape 1 — Accéder au menu

  1. Connecte-toi à l'interface Web d'administration de Sophos.
  2. Ouvre Hosts and services.
  3. Selon la version de SFOS, le menu peut être présenté sous Network > IP host ou un emplacement équivalent.

Étape 2 — Ajouter l'adresse

  1. Clique sur Add ou Add IP host.
  2. Renseigne les paramètres suivants.
Name
IP_BLOQUEE
IP version
IPv4
Type
IP / Host, selon l'interface
IP address
203.0.113.50 — exemple à remplacer par l'adresse réelle

Pour une seule adresse IPv4, utilise l'adresse seule, sans masque de sous-réseau. Vérifie le type de l'objet avant de l'enregistrer.

Étape 3 — Enregistrer

  1. Clique sur Save.
  2. Vérifie que l'objet IP_BLOQUEE apparaît dans la liste.
  3. Tu peux maintenant le sélectionner dans les règles Firewall.

3. Créer la règle de blocage

Ouvre Rules and policies > Firewall rules. Clique sur Add firewall rule > New firewall rule, ou sur l'option équivalente de ta version.

Configuration de la règle

Exemple : bloquer l'adresse publique 203.0.113.50 qui tente d'accéder au réseau LAN.

Champ Valeur
Rule name BLOCK_IP_PUBLIQUE
Rule position Top — placer en haut si nécessaire
Action Drop
Source zones WAN
Source networks and devices IP_BLOQUEE
Destination zones LAN
Destination networks Any
Services Any
Log firewall traffic Activé

Enregistrer et activer la règle

  1. Vérifie tous les champs de la règle.
  2. Clique sur Save.
  3. Vérifie que la règle est activée.
  4. Place-la au-dessus des règles susceptibles d'autoriser le même trafic.
  5. Contrôle les journaux après avoir testé le blocage.
À retenir : Sophos évalue les règles Firewall selon leur ordre et les critères de correspondance. Une règle de blocage placée au-dessus des règles d'autorisation pertinentes évite que le trafic visé soit accepté par une règle plus prioritaire.
Attention à l'adresse d'exemple : 203.0.113.50 appartient à une plage réservée à la documentation. Ce n'est pas une véritable adresse publique à utiliser pour un test réel. Remplace-la par l'adresse que tu veux bloquer.

Attention également : une règle WAN vers LAN ne couvre pas nécessairement tous les scénarios, notamment les accès à des services publiés, les règles DNAT ou les autres chemins réseau. Adapte les zones à la topologie réelle de ton installation.

4. Vérifier que le blocage fonctionne

Après avoir enregistré la règle, contrôle les journaux et vérifie que le trafic correspondant est effectivement bloqué.

Étape 1 — Ouvrir les journaux

Ouvre Log viewer ou la section des journaux Firewall dans l'interface d'administration Sophos.

Étape 2 — Rechercher l'adresse IP

Filtre les événements avec l'adresse IP concernée. Selon le type de trafic, vérifie l'adresse source, l'adresse destination et la règle indiquée dans le journal.

Étape 3 — Confirmer le résultat

Si le trafic passe encore : vérifie les zones, le sens du trafic, l'ordre des règles et les règles NAT éventuelles. Vérifie également si une session existante est toujours active. Le comportement des connexions déjà établies peut différer de celui des nouvelles connexions.
Résultat attendu : les nouvelles connexions correspondant aux critères de la règle de blocage sont rejetées et les événements correspondants peuvent être examinés dans les journaux.

5. Bloquer une IP interne

Pour empêcher un poste du LAN d'accéder à Internet, crée d'abord un objet IP correspondant à l'adresse interne du poste, par exemple 192.168.1.50. Ensuite, configure une règle spécifique.

Configuration de la règle LAN vers WAN

Champ Valeur
Rule name BLOCK_IP_INTERNE
Source zone LAN
Source networks and devices IP_BLOQUEE
Destination zone WAN
Destination networks Any
Services Any
Action Drop
Rule position Top — avant les autorisations pertinentes
Log firewall traffic Activé

Procédure

  1. Crée l'objet IP du poste interne.
  2. Ouvre Rules and policies > Firewall rules.
  3. Ajoute une nouvelle règle Firewall.
  4. Choisis LAN comme zone source et WAN comme zone destination.
  5. Sélectionne l'objet IP du poste comme source.
  6. Choisis Drop comme action.
  7. Active les journaux et enregistre la règle.
  8. Place la règle au-dessus des autorisations qui pourraient correspondre au trafic.
  9. Teste l'accès à Internet depuis le poste et vérifie les journaux.
Limite : cette règle vise le trafic du poste interne vers Internet. Pour bloquer aussi les communications entre VLAN, LAN et autres zones internes, ajoute les règles adaptées à ces chemins réseau. Vérifie également les accès IPv6 si ton réseau les utilise.

Documentation officielle

Pour vérifier les options exactes de ton interface SFOS, consulte la documentation Sophos :

  • Créer une règle Firewall Sophos
  • Gérer les objets IP Host
Avant toute modification en production : vérifie que tu utilises la bonne adresse IP, que tu ne bloques pas une adresse d'administration essentielle et que la nouvelle règle ne perturbera pas les services autorisés. Si possible, effectue les tests pendant une fenêtre de maintenance et conserve un accès d'administration de secours.
